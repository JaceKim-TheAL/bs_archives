### 피보나치라인

### ln[피보나치.분봉]
> - 가격 되돌림(조정)이나 반등을 멈출 가능성이 높은 지지,저항 구간을 표시하는 도구 
> - 주요 되돌림비율 : 23.6&, 38.2%, 5.00%, 61.8%, 78.6%
> - 특히 0.618(황금비율) 
> - 확장 비율 : 127.2%, 161.8%, 261.8%

- 되돌림 해석
  - [x] 38.2% : 강세장에서 자주 반응하는 얕은 조정 구간
  - [x]  50.0% : 심리적 반 토막 구간,   매수/매도 세력 모두 주목
  - [x]  61.8% : 황금비율, 가장 강력한 지지/저항 구간
  - [x]  78.6% : 거의 원래 가격까지 되돌린 깊은 조정, 추세 약화 신호

<br/>

[수식]

```
DH = dayhigh();
DL1 = daylow();
DL2 = PreDayClose();
DL = min(DL1, DL2);
BH = DH-DL;

F1 = DH - (BH*조정대1/1000); 
F2 = DH - (BH*조정대2/1000); 
F3 = DH - (BH*조정대3/1000); 
F4 = DH - (BH*조정대4/1000); 
F5 = DH - (BH*조정대5/1000); 

F1

```
